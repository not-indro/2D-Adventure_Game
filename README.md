
2D-Adventure Game: Harry Potter Edition

This is a 2D adventure game set in the world of Harry Potter, utilizing procedural content generation for dynamic background creation. The game invites players to explore iconic locations, solve puzzles, and battle magical creatures in a unique and immersive way.
Features

    Procedural Content Generation: Each playthrough offers different backgrounds and landscapes, keeping the experience fresh and engaging.
    Adventure Elements: Players navigate the game as a Hogwarts student, completing quests, learning spells, and uncovering secrets.
    Dynamic Backgrounds: No two scenes are alike thanks to the procedural generation system, adding variety to each play session.

How to Play

    Install Dependencies: Make sure you have the required game engine or software (Unity, Godot, etc.).
    Launch the Game: Follow the setup instructions provided in the release files to start your adventure.
    Explore the World: Use the arrow keys or joystick to move, and spacebar or action button to interact with the environment.
